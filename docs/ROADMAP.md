# 8-Week Roadmap: Associate Cloud Engineer (ACE)

Target: pass the **Google Cloud Associate Cloud Engineer** exam and have six documented projects on GitHub and LinkedIn.
Check the current exam fee, length and format on the official page before booking: https://cloud.google.com/learn/certification/cloud-engineer

Allow 1 to 1.5 hours a day. Use **Google Cloud Skills Boost** (cloudskillsboost.google) for guided labs. They run in temporary projects, so they cost nothing on your own billing account. Use your own project for the portfolio builds below.

| Week | Learn (Skills Boost) | Build (this repo) | Post on LinkedIn |
|------|----------------------|-------------------|------------------|
| 1 | Google Cloud Fundamentals: Core Infrastructure; resource hierarchy, projects, billing, Cloud Shell | Setup + budget (docs/SETUP.md) | "Starting my Google Cloud journey" |
| 2 | Networking in Google Cloud: VPC, subnets, routes, firewall rules, Cloud NAT, IAP | **01 Secure VPC network** | Project 01 post |
| 3 | Compute Engine, instance templates, MIGs, load balancing | **02 Load-balanced web app** | Project 02 post |
| 4 | Cloud Storage classes, IAM on buckets, versioning, lifecycle | **03 Static website** | Project 03 post |
| 5 | IAM: roles, service accounts, custom roles, audit logs | **04 IAM least privilege** | Project 04 post |
| 6 | Cloud Monitoring and Logging, Ops Agent, alerting, billing | **05 Monitoring and budget** | Project 05 post |
| 7 | Terraform on Google Cloud; GKE (Google Kubernetes Engine) and Cloud Run basics | **06 Terraform VPC** | Project 06 post + skill badges |
| 8 | ACE official exam guide, sample questions, practice exams; review weak domains | Polish READMEs and screenshots | Book exam, then announce certification |

## Skill badges to earn (shareable on LinkedIn via Credly)

Search for these in Skills Boost. Names change, so pick the closest current version:
- Set Up an App Dev Environment on Google Cloud
- Develop your Google Cloud Network
- Build a Secure Google Cloud Network
- Implement Load Balancing on Compute Engine
- Build Infrastructure with Terraform on Google Cloud

## Exam domains to cover

1. Setting up a cloud solution environment
2. Planning and implementing a cloud solution
3. Ensuring successful operation of a cloud solution
4. Configuring access and security

## After ACE

The natural next step for a network engineer path is **Professional Cloud Network Engineer**. It builds directly on projects 01, 02 and 06: hybrid connectivity (Cloud VPN, Cloud Interconnect), VPC peering, Shared VPC and Cloud DNS (Domain Name System).
